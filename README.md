# 🎲 FichaCraft

> Suas aventuras. Suas fichas. Seu mundo.

## 📖 Sobre o projeto

A FichaCraft é uma empresa fictícia de tecnologia voltada para jogadores e Mestres
de RPG de mesa.

O projeto consiste no desenvolvimento de um site institucional para apresentar
uma plataforma de criação e gerenciamento de RPG, com recursos como criação
automática de fichas, organização de personagens, gerenciamento de campanhas,
NPCs e sessões.

O site foi desenvolvido como parte da atividade prática de desenvolvimento
colaborativo com Git e GitHub.

## 🎯 Objetivo

Criar uma experiência digital que facilite a organização de personagens e
campanhas de RPG, reunindo diferentes recursos em uma única plataforma.

## 🧩 Recursos apresentados

- 🎲 Criação de fichas de personagens
- ⚔️ Personalização de personagens
- 🗺️ Gerenciamento de campanhas
- 👹 Organização de NPCs
- 📖 Organização de sessões
- 📚 Suporte conceitual a diferentes sistemas de RPG
